# 视觉风格系统

## 默认规则

未收到用户明确的视觉要求时，统一使用 `warm-editorial-proof`。这是通用默认主体风格：暖纸编辑设计承载内容，深色品牌片头片尾形成节奏反差。

不要因为内容涉及 AI、代码或 Agent，就自动切换到深蓝紫科技风。默认风格已经为技术内容准备了等宽标签、阶段进度、语义配色和证据卡片。

只有以下情况允许切换 preset：

- 用户明确指定另一种风格、参考图或品牌规范。
- 用户要求以真实产品截图或录屏为绝对主体，此时可以使用 `product-demo-clean`。
- 用户明确要求左右对比、数据报告或深色科技视觉。

在 `分镜脚本.md` 顶部写明：

```markdown
visualStyle: warm-editorial-proof
styleReason: 默认使用暖纸编辑风，以清晰层级和语义配色承载技术内容；深色片头片尾保留品牌识别。
palette: 暖纸 #F3EDDC、纸白 #FFFDF8、深墨 #1D252C、珊瑚 #D85B3F、本体绿 #397A64、验收蓝 #486A92、实现紫 #765B8F。
typography: 中文标题使用宋体族；正文使用黑体族；英文标签、编号、代码和状态使用等宽字体。
layoutRules: 1080x1920；顶部阶段条 48-144；标题从 Y=184 开始；主体底边不超过 Y=1380；字幕区从 Y=1450 开始。
motionRules: 只使用帧驱动的淡入、短位移、节点点亮和连线；先稳定呈现信息，再增加动画。
```

## 视觉基准

参考用户提供的视觉参考图；未提供时以本文件的文字规范为准。

参考图用于校准颜色、字号层级、留白、卡片密度、字幕关系和阶段感，不要照抄其中的具体业务文字。

## Default：warm-editorial-proof

### 画布与背景

- 默认画布：`1080 x 1920`，`30fps`。
- 主体背景：暖纸色 `#F3EDDC`。
- 信息块背景：纸白 `#FFFDF8` 或语义浅色。
- 纸张纹理：每 48px 一条极淡横线，透明度约 `0.13`。
- 正文颜色：深墨 `#1D252C`；次要文字 `#756F66`；分隔线 `#C9C1B2`。
- 主体场景不使用渐变、发光、玻璃拟态或装饰性光斑。

### 字体层级

- 大标题：`Songti SC, STSong, SimSun, serif`，72-84px，行高 1.12-1.16。
- 封面标题：118-132px，行高 1.05-1.1。
- 正文：`PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif`，24-34px。
- 英文标签、编号、代码、状态：`SFMono-Regular, Menlo, Consolas, monospace`，16-24px。
- 中文标题负责叙事，等宽英文只负责结构和状态，不要让两者争抢视觉焦点。

### 语义色板

| 角色 | 色值 | 用法 |
|------|------|------|
| 结论 / 问题 | `#D85B3F` | 关键判断、问题、结论线 |
| 第一语义组 | `#397A64` | 定义、业务含义、确认状态 |
| 第二语义组 | `#486A92` | 验收、审查、约束、裁决 |
| 第三语义组 | `#765B8F` | 实现、测试、生成、执行 |
| 品牌强调色 | `#66BB6A` | 可由用户提供的品牌色替换 |
| 辅助强调色 | `#FBBF24` | 可由用户提供的辅助品牌色替换 |

语义色按内容角色映射，不要求所有视频都使用“本体 / 验收 / TDD”这三个名字。需要更多分类时，优先复用这三组色，不新增相近色。

### 页面骨架

- 顶部阶段条：`top: 48px; left/right: 64px; height: 96px`，使用细边线和顶部 4px 状态色。
- 主内容：`padding: 184px 64px 280px`。
- 小节标签：18-20px 等宽体，使用当前场景强调色。
- 主标题：标签下方 25px，最大宽度约 930px。
- 主体信息：从标题后 30-60px 开始，控制在 `Y <= 1320-1380`。
- 页脚状态线：`top: 1380px`，左右各 64px，16px 等宽体。
- 字幕容器：左右 64px，底部 70px，最多 2 行，不遮挡页脚以上的主体内容。

### 信息组件

- 卡片圆角默认为 0-4px，不使用大圆角卡片墙。
- 通过 `borderTop` 或 `borderLeft` 的 4-7px 语义色建立分类，不依赖阴影。
- 同屏多项采用稳定网格或纵向列表，编号列、标题列、状态列对齐。
- 技能名、接口名、引用和状态使用等宽字体，可用 1px 描边标签。
- 结论使用珊瑚色文字 + 上边线，不放进额外卡片。
- 流程必须先显示总览，再逐步点亮；不要突然开始逐项介绍。

### 动效

- 默认入场：0.4-0.8 秒淡入 + 12-20px 短位移。
- 列表逐项延迟：0.35-0.6 秒；复杂讲解可按口播节奏延长。
- 阶段条只改变顶部状态色和透明度，不做跳动或发光。
- 允许节点连接、印章落下、RED/GREEN 状态切换等有语义的动画。
- 不默认使用 Lottie。只有动画能解释口播内容时才加入。
- 每个场景开始 0.5 秒内应出现首个可读主体；结束前保留稳定画面。

### 品牌片头片尾

- 封面和主体使用暖纸编辑风。
- 品牌片头片尾使用深色 `#111722` 到 `#202538` 的克制渐变，形成章节边界。
- 深色品牌场景按用户提供的品牌资产和规范制作。
- 深色只用于品牌场景，不扩散到默认主体页面。

## 内容适配

| 内容场景 | 默认适配方式 |
|---------|-------------|
| 概念科普 | 术语定义卡 + 关系图 + 珊瑚结论 |
| 方法论 / 工作流 | 顶部阶段条 + 总览场景 + 分步点亮 |
| 技能 / 工具介绍 | 先给能力地图，再逐项介绍，技能名使用等宽标签 |
| 产品 demo | 暖纸标题区 + 真实截图主体；必要时显式切换 `product-demo-clean` |
| 技术对比 | 暖纸底上的双列对比，使用蓝 / 紫两组语义色 |
| 趋势 / 数据 | 暖纸报告风时间线，珊瑚色标注变化结论 |
| 个人观点 | 大标题 + 少量证据条目 + 珊瑚结论，不堆卡片 |

## 可选 Preset

### product-demo-clean

用于用户明确要求以真实界面、截图或录屏为主体的工具演示。浅灰白背景，截图占主要面积，文字只做结论和标注。

### debate-contrast

用于用户明确要求强对比或选择题视觉。左右分栏，两组对比色，逐维度高亮，最后聚焦结论。

### data-timeline-report

用于用户明确要求数据报告、时间线或新闻事件视觉。时间线、数据卡和变化节点是主体。

### tech-dark-brand

用于用户明确要求全片深色科技风。深蓝紫背景、光晕和科技线条只能在这种显式请求下使用。

## 抽帧检查追加项

- 是否与本文件定义的暖纸编辑风保持一致。
- 暖纸、深墨、宋体标题、等宽标签和语义色是否稳定。
- 是否出现无意义渐变、玻璃态、大圆角卡片、发光或装饰性 Lottie。
- 是否先给总览再逐项展开，避免叙事突然跳入列表。
- 阶段条、标题、主体、页脚和字幕是否各自占据稳定区域。
- 深色背景是否仅用于品牌片头片尾，除非用户明确要求全片深色。

发现风格偏离时，修改主题和场景代码后重新抽帧，不要只报告问题。
